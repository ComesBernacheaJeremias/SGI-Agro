### Problemas / aprendizajes
- Librerías muy nuevas: TypeScript 7 no es compatible con typescript-eslint ni openapi-typescript → se fijó **TS 5.9**. Starlette pide **httpx2** para el TestClient.
- `func.lower("username")` genera `lower('username')` (literal): el índice funcional se define fuera de la clase con `func.lower(User.username)`.
- `es-AR` en `Intl.NumberFormat` no agrupa miles de 4 dígitos → `useGrouping: 'always'`.
- Scripts Python en Windows escriben CRLF: usar `newline="
"`; `.gitattributes` fuerza LF en el repo.
