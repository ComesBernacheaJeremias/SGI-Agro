## Decisiones tomadas
- Sin carga sin conexión: cubría una parte chica del sistema (no compras, ventas, cobros ni caja), tenía un bug y no se habló con el cliente. Si se corta internet, se usan los datos del celular.
- No hacer planillas Excel para cargar sin señal e importar después: mucho trabajo para un caso rarísimo; se evalúa si el cliente lo pide.

- Paleta "Monte" (verde bosque), color solo con significado; el logo lo busca el usuario con estos colores.
- Cosecha: sigue entrando al stock a costo cero; se muestra valorizada por costo del ciclo solo como dato. Que entre con costo, solo si el cliente lo pide.

## Problemas / aprendizajes
- El contenedor `web` tiene su propio `node_modules`: al instalar un paquete hay que correr `docker compose exec web npm install` y reiniciar `web` (Vite recuerda el import que no encontró).
- El bug: dos `createStore` de `idb-keyval` sobre la misma base IndexedDB (`sgi-offline`) → solo se crea el primer espacio. Los tests (jsdom) no lo detectaban; se vio recién en Chrome. Quedó sin efecto al quitar la función.
